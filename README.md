**Line:** "My manager blocks thirty minutes of 'focus time' before every meeting, then spends it being late to the meeting before that one."

The setup is a calendar habit nearly every office worker has seen: a protective "focus time" block dropped in just ahead of a meeting so the day looks manageable.

## Run it

```bash
python3 main.py
```

Writes the joke to `/output/entry.txt`. If `MAKEFUN_OUTPUT_DIR` is set, the file
goes to `$MAKEFUN_OUTPUT_DIR/entry.txt` instead.

No network, no randomness, no arguments: the text is a constant in `main.py`,
written as UTF-8 bytes with no trailing newline.
